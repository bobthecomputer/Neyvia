# nxOnboardingModel

Provides STEPS, STEP_LABELS, stepFor, UNLOCKS for Neyvia's UI state and behavior.

- **Public API:** `STEPS`, `STEP_LABELS`, `TOUR_MAX_MS`, `TOUR_MIN_MS`, `UNLOCKS`, `componentGroups`, `componentView`, `downloadView`, `essentialsView`, `formatBytes`, `interestsFor`, `locate`, `packView`, `packsBusy`, `plainMissing`, `recommend`, `runtimeHeadline`, `stepFor`, `timeline`, `toggle`, `uniqueChapters`.
- **Manual:** [neyvia.cl](../../manuals/cl/neyvia.cl), [onboarding.cl](../../manuals/cl/onboarding.cl), [slim-installer.cl](../../manuals/cl/slim-installer.cl).
- **Contracts:** `run modules.verify-map()`.
- **Outcome contracts:** `onboarding.downloadView`, `onboarding.interestsFor`, `onboarding.locate`, `onboarding.packView`, `onboarding.plainMissing`, `onboarding.recommend`, `onboarding.runtimeHeadline`, `onboarding.timeline`, `p22.onboarding.first-run-snapshot`.
- **Dependencies:** [surface.nxProofsEContracts](../surface.nxProofsEContracts/README.md).
- **Owner:** Neyvia / nxOnboardingModel.
- **Files:** [web/src/neyvia/next/nxOnboardingModel.js](../../web/src/neyvia/next/nxOnboardingModel.js).
