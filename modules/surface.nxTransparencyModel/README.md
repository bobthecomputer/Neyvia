# nxTransparencyModel

Provides TRANSPARENCY_LEVELS, TRANSPARENCY_LABELS, stripAnsi, toolFailed for Neyvia's UI state and behavior.

- **Public API:** `TRANSPARENCY_LABELS`, `TRANSPARENCY_LEVELS`, `detailExpanded`, `detailText`, `diffText`, `itemVisible`, `normalizeTransparency`, `reasoningNotice`, `stripAnsi`, `toolDetails`, `toolFailed`, `toolMetadata`, `visibleTranscriptItems`.
- **Manual:** [neyvia.cl](../../manuals/cl/neyvia.cl), [transparency.cl](../../manuals/cl/transparency.cl).
- **Contracts:** `run modules.verify-map()`.
- **Outcome contracts:** `transparency.details`, `transparency.expanded`, `transparency.metadata`, `transparency.normalize`, `transparency.notice`, `transparency.patch`, `transparency.quiet-unreported`, `transparency.text`, `transparency.visible`.
- **Dependencies:** [surface.neyviaPresentationContracts](../surface.neyviaPresentationContracts/README.md).
- **Owner:** Neyvia / nxTransparencyModel.
- **Files:** [web/src/neyvia/next/nxTransparencyModel.js](../../web/src/neyvia/next/nxTransparencyModel.js).
