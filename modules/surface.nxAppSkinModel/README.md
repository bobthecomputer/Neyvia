# nxAppSkinModel

Provides SKINS, THEME_IDS, skinTone, skinFor for Neyvia's UI state and behavior.

- **Public API:** `SKINS`, `THEME_IDS`, `allSkins`, `cachedSkinTokens`, `skinFor`, `skinPalette`, `skinTokens`, `skinTone`.
- **Manual:** [design.cl](../../manuals/cl/design.cl), [neyvia.cl](../../manuals/cl/neyvia.cl).
- **Contracts:** `run modules.verify-map()`.
- **Outcome contracts:** `appskin.skinFor`, `appskin.skinPalette`, `appskin.skinTokens`.
- **Dependencies:** [surface.nxProofsEContracts](../surface.nxProofsEContracts/README.md), [surface.nxThemeRegistry](../surface.nxThemeRegistry/README.md).
- **Owner:** Neyvia / nxAppSkinModel.
- **Files:** [web/src/neyvia/next/nxAppSkinModel.js](../../web/src/neyvia/next/nxAppSkinModel.js).
