# nxMissionsModel

Provides HARNESSES, harnessLabel, markForHarness, emptyDraft for Neyvia's UI state and behavior.

- **Public API:** `HARNESSES`, `createRequest`, `draftProblems`, `emptyDraft`, `emptyTask`, `harnessLabel`, `markForHarness`, `planPrompt`, `shapeMission`.
- **Manual:** [mission-plan.cl](../../manuals/cl/mission-plan.cl), [neyvia.cl](../../manuals/cl/neyvia.cl).
- **Contracts:** `run modules.verify-map()`.
- **Outcome contracts:** `missions.createRequest`, `missions.draftProblems`, `missions.planPrompt`, `missions.shapeMission`.
- **Dependencies:** [surface.nxProofsEContracts](../surface.nxProofsEContracts/README.md).
- **Owner:** Neyvia / nxMissionsModel.
- **Files:** [web/src/neyvia/next/nxMissionsModel.js](../../web/src/neyvia/next/nxMissionsModel.js).
