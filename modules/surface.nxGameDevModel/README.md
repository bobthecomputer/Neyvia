# nxGameDevModel

Provides ENGINE_TABS, APP_TABS, engineState, isBrowserScene for Neyvia's UI state and behavior.

- **Public API:** `ACTION_WORDS`, `APP_TABS`, `ENGINE_TABS`, `actionFields`, `buildArgs`, `engineState`, `folderName`, `formatVector`, `friendlyError`, `initialValues`, `isBrowserScene`, `isDone`, `keepSelection`, `latestTree`, `newRequestId`, `receiptState`, `sessionLabel`, `sessionState`, `shortPath`, `sortSessions`, `tabForStage`, `visibleFields`.
- **Manual:** [game-dev.cl](../../manuals/cl/game-dev.cl), [neyvia.cl](../../manuals/cl/neyvia.cl).
- **Contracts:** `run modules.verify-map()`.
- **Outcome contracts:** `gamedev.actionFields`, `gamedev.buildArgs`, `gamedev.initialValues`, `gamedev.keepSelection`, `gamedev.sessionLabel`, `gamedev.tabForStage`, `gamedev.visibleFields`.
- **Dependencies:** [surface.nxProofsEContracts](../surface.nxProofsEContracts/README.md).
- **Owner:** Neyvia / nxGameDevModel.
- **Files:** [web/src/neyvia/next/nxGameDevModel.js](../../web/src/neyvia/next/nxGameDevModel.js).
