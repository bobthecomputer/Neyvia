# nxSunModel

Provides BLEND_MINUTES, minutesOfDay, dayPartAt, daylightAt for Neyvia's UI state and behavior.

- **Public API:** `BLEND_MINUTES`, `BLEND_TARGET`, `INKS`, `PALETTE_VARS`, `SURFACES`, `blendVars`, `dayPartAt`, `daylightAt`, `followedTheme`, `horizonAt`, `inkOn`, `lampPaletteOf`, `meetingColor`, `minutesOfDay`, `mixHex`, `mixPalettes`.
- **Manual:** [neyvia.cl](../../manuals/cl/neyvia.cl).
- **Contracts:** `run modules.verify-map()`.
- **Outcome contracts:** No outcome binding yet.
- **Dependencies:** [surface.nxLookModel](../surface.nxLookModel/README.md), [surface.nxThemeRegistry](../surface.nxThemeRegistry/README.md).
- **Owner:** Neyvia / nxSunModel.
- **Files:** [web/src/neyvia/next/nxSunModel.js](../../web/src/neyvia/next/nxSunModel.js).
