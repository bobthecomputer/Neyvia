# nxPopout

Provides POPOUT_HINT, POPOUT_KEY, usePopout, getPopout for Neyvia's UI state and behavior.

- **Public API:** `POPOUT_HINT`, `POPOUT_KEY`, `POPOUT_MIN`, `bindPopoutSession`, `closePopout`, `contextBlock`, `geometryFor`, `getPopout`, `openPopout`, `saveGeometry`, `setPopoutNewChat`, `setPopoutPending`, `toggleExpanded`, `usePopout`, `windowContext`, `windowForShortcut`.
- **Manual:** [neyvia.cl](../../manuals/cl/neyvia.cl).
- **Contracts:** `run modules.verify-map()`.
- **Outcome contracts:** No outcome binding yet.
