# nxConductorModel

Provides PROFILES, phaseOf, taskTone, conductorOf for Neyvia's UI state and behavior.

- **Public API:** `PROFILES`, `checkLines`, `conductorOf`, `durationText`, `mergeJobs`, `phaseOf`, `planProblems`, `routeLine`, `shapeJob`, `taskTone`, `turnKind`.
- **Manual:** [conductor.cl](../../manuals/cl/conductor.cl), [neyvia.cl](../../manuals/cl/neyvia.cl).
- **Contracts:** `run modules.verify-map()`.
- **Outcome contracts:** `conductor.mergeJobs`, `conductor.planProblems`, `conductor.shapeJob`, `conductor.turnKind`.
- **Dependencies:** [surface.nxProofsEContracts](../surface.nxProofsEContracts/README.md).
- **Owner:** Neyvia / nxConductorModel.
- **Files:** [web/src/neyvia/next/nxConductorModel.js](../../web/src/neyvia/next/nxConductorModel.js).
