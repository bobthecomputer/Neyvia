# nxAccountsModel

Provides USERNAME_PATTERN, PASSWORD_MIN, STRENGTH_LABELS, initials for Neyvia's UI state and behavior.

- **Public API:** `PASSWORD_MIN`, `STRENGTH_LABELS`, `USERNAME_PATTERN`, `avatarHue`, `deviceKind`, `generatePassword`, `initials`, `lastSeen`, `newAccountProblem`, `passwordStrength`.
- **Manual:** [neyvia.cl](../../manuals/cl/neyvia.cl).
- **Contracts:** `run modules.verify-map()`.
- **Outcome contracts:** `accounts.avatar`, `accounts.device`, `accounts.form`, `accounts.generated-password`, `accounts.initials`, `accounts.last-seen`, `accounts.strength`.
- **Dependencies:** [surface.nxModelContracts](../surface.nxModelContracts/README.md).
- **Owner:** Neyvia / nxAccountsModel.
- **Files:** [web/src/neyvia/next/nxAccountsModel.js](../../web/src/neyvia/next/nxAccountsModel.js).
