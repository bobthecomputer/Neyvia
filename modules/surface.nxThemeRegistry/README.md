- **Public API:** `DEFAULT_THEME`, `THEMES`, `THEME_BLURBS`, `THEME_DAYPAIR`, `THEME_FROM_SETTINGS`, `THEME_IDEAS`, `THEME_INK`, `THEME_LABELS`, `THEME_REGISTRY`, `THEME_SCHEME`, `THEME_SHIFT`, `THEME_TO_SETTINGS`, `canFollowSun`, `isTheme`.
- **Manual:** [neyvia.cl](../../manuals/cl/neyvia.cl).
- **Contracts:** `run modules.verify-map()`.
- **Outcome contracts:** No outcome binding yet.
- **Dependencies:** None statically declared.
- **Owner:** Neyvia / nxThemeRegistry.
