# neyviaMotion

Provides NEYVIA_REDUCE_MOTION_ATTR, NEYVIA_REDUCE_MOTION_FALLBACK_ATTR, applyNeyviaReduceMotion, isNeyviaMotionReduced for Neyvia's UI state and behavior.

- **Manual:** [neyvia.cl](../../manuals/cl/neyvia.cl), [settings.cl](../../manuals/cl/settings.cl).
- **Contracts:** `run modules.verify-map()`.
- **Outcome contracts:** `preferences.motion`.
- **Dependencies:** [surface.neyviaFrontendContracts](../surface.neyviaFrontendContracts/README.md), [surface.neyviaToolVisuals](../surface.neyviaToolVisuals/README.md).
- **Owner:** Neyvia / neyviaMotion.
