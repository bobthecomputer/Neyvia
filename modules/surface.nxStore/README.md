# nxStore

Provides isRunActive, useNx, getNx, insertItem for Neyvia's UI state and behavior.

- **Public API:** `clearFixture`, `getNx`, `insertItem`, `isFixtureId`, `isRunActive`, `isWorkingElsewhere`, `loadList`, `markSeen`, `nextMessageSequence`, `setAmplifyLearning`, `setFeedback`, `stageFixture`, `startLive`, `useNx`, `waitForRunSession`.
- **Manual:** [neyvia.cl](../../manuals/cl/neyvia.cl).
- **Contracts:** `run modules.verify-map()`.
- **Outcome contracts:** No outcome binding yet.
- **Dependencies:** [surface.nxApi](../surface.nxApi/README.md), [surface.nxComposerModel](../surface.nxComposerModel/README.md), [surface.nxPlanModel](../surface.nxPlanModel/README.md).
- **Owner:** Neyvia / nxStore.
