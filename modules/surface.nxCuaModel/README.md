# nxCuaModel

Provides boxStyle, agentName, entryText, effectLabel for Neyvia's UI state and behavior.

- **Public API:** `agentName`, `boxStyle`, `effectLabel`, `elementAt`, `entryText`, `keyToInput`, `mergeLog`, `pickSession`, `refusalText`, `toCapture`, `wheelToScroll`.
- **Manual:** [computer-use.cl](../../manuals/cl/computer-use.cl), [neyvia.cl](../../manuals/cl/neyvia.cl).
- **Contracts:** `run modules.verify-map()`.
- **Outcome contracts:** `cua.elementAt`, `cua.keyToInput`, `cua.mergeLog`, `cua.pickSession`, `cua.toCapture`, `cua.wheelToScroll`.
- **Dependencies:** [surface.nxProofsEContracts](../surface.nxProofsEContracts/README.md).
- **Owner:** Neyvia / nxCuaModel.
- **Files:** [web/src/neyvia/next/nxCuaModel.js](../../web/src/neyvia/next/nxCuaModel.js).
