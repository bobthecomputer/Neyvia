# neyviaMarketplaceModel

Provides MARKETPLACE_UNAVAILABLE, marketplaceCompatibility, MARKETPLACE_BACKEND_COMMANDS, marketplaceStateTone for Neyvia's UI state and behavior.

- **Public API:** `MARKETPLACE_BACKEND_COMMANDS`, `MARKETPLACE_UNAVAILABLE`, `marketplaceCompatibility`, `marketplaceStateTone`, `normalizeMarketplaceSnapshots`, `shortMarketplaceIdentity`.
- **Manual:** [neyvia.cl](../../manuals/cl/neyvia.cl).
- **Contracts:** `run modules.verify-map()`.
- **Outcome contracts:** `marketplace.snapshots`.
- **Dependencies:** [surface.neyviaPresentationContracts](../surface.neyviaPresentationContracts/README.md).
- **Owner:** Neyvia / neyviaMarketplaceModel.
- **Files:** [web/src/neyvia/neyviaMarketplaceModel.js](../../web/src/neyvia/neyviaMarketplaceModel.js).
