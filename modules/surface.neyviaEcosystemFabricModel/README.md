# neyviaEcosystemFabricModel

Provides COMMUNICATION_ROUTES, COMMUNICATION_STATES, PRESENTATION_PROFILES, normalizeCommunicationFabric for Neyvia's UI state and behavior.

- **Public API:** `COMMUNICATION_ROUTES`, `COMMUNICATION_STATES`, `PRESENTATION_PROFILES`, `buildCommunicationAccountPayload`, `canInsertPresentationPrompt`, `communicationStateTone`, `normalizeCommunicationFabric`, `permissionApprovalLabel`.
- **Manual:** [neyvia.cl](../../manuals/cl/neyvia.cl).
- **Contracts:** `run modules.verify-map()`.
- **Outcome contracts:** `fabric.account`, `fabric.approval`, `fabric.insert`, `fabric.normalize`, `fabric.tone`.
- **Dependencies:** [surface.neyviaFrontendContracts](../surface.neyviaFrontendContracts/README.md).
- **Owner:** Neyvia / neyviaEcosystemFabricModel.
- **Files:** [web/src/neyvia/neyviaEcosystemFabricModel.js](../../web/src/neyvia/neyviaEcosystemFabricModel.js).
