# nxPdfModel

Provides loadPdfjs, rectsForText, toBox, selectionRects for Neyvia's UI state and behavior.

- **Public API:** `ZOOM_STEPS`, `clampPage`, `displayName`, `itemRect`, `loadPdfjs`, `rectsForText`, `searchTexts`, `selectionRects`, `stepZoom`, `toBox`.
- **Manual:** [neyvia.cl](../../manuals/cl/neyvia.cl), [pdf.cl](../../manuals/cl/pdf.cl).
- **Contracts:** `run modules.verify-map()`.
- **Outcome contracts:** `p22.pdf-render`, `pdf.display-name`, `pdf.page`, `pdf.search`, `pdf.text-geometry`, `pdf.zoom`.
- **Dependencies:** [surface.nxApi](../surface.nxApi/README.md), [surface.nxModelContracts](../surface.nxModelContracts/README.md).
- **Owner:** Neyvia / nxPdfModel.
- **Files:** [web/src/neyvia/next/nxPdfModel.js](../../web/src/neyvia/next/nxPdfModel.js).
