- **Public API:** `REQUIREMENT_LABELS`, `WORKFLOWS`, `explain`, `listWorkflows`, `suggestWorkflows`, `workflowAvailability`.
- **Manual:** [neyvia.cl](../../manuals/cl/neyvia.cl).
- **Contracts:** `run modules.verify-map()`.
- **Outcome contracts:** `workflow.availability`, `workflow.explain`, `workflow.list`.
- **Dependencies:** [surface.neyviaFrontendContracts](../surface.neyviaFrontendContracts/README.md).
- **Owner:** Neyvia / neyviaWorkflows.
- **Files:** [web/src/neyvia/neyviaWorkflows.js](../../web/src/neyvia/neyviaWorkflows.js).
