# pdf_compat

Permissive PDF helpers: pypdf (BSD) reads text and fonts and writes PDFs, pypdfium2 (Apache-2.0/BSD-3, PDFium) renders pages.

- **Public API:** `Canvas`, `fonts`, `locked`, `page_count`, `page_size`, `page_texts`, `render`, `text`.
- **Manual:** [neyvia.cl](../../manuals/cl/neyvia.cl).
- **Contracts:** `run modules.verify-map()`.

- **Dependencies:** None statically declared.
