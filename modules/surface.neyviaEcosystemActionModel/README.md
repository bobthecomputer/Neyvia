# neyviaEcosystemActionModel

Provides buildPresentationCapturePayload, buildBenchmarkResultPayload, canSubmitBenchmarkResult, canConcludeExperiment for Neyvia's UI state and behavior.

- **Public API:** `buildBenchmarkResultPayload`, `buildPresentationCapturePayload`, `canConcludeExperiment`, `canSubmitBenchmarkResult`.
- **Manual:** [neyvia.cl](../../manuals/cl/neyvia.cl).
- **Contracts:** `run modules.verify-map()`.
- **Outcome contracts:** `ecosystem.benchmark`, `ecosystem.capture`, `ecosystem.conclude`, `ecosystem.submit`.
- **Dependencies:** [surface.neyviaFrontendContracts](../surface.neyviaFrontendContracts/README.md).
- **Owner:** Neyvia / neyviaEcosystemActionModel.
- **Files:** [web/src/neyvia/neyviaEcosystemActionModel.js](../../web/src/neyvia/neyviaEcosystemActionModel.js).
