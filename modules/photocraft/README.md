# PhotoCraft

Agent-usable PhotoCraft (ArtCraft/storytold, a Photoshop-style editor in Rust) for video frames: inspect, run engine commands, convert.

- **Public API:** `commands`, `convert`, `info`, `run`, `verify`, `neyvia.mod.photocraft.commands`, `neyvia.mod.photocraft.convert`, `neyvia.mod.photocraft.info`, `neyvia.mod.photocraft.run`, `neyvia.mod.photocraft.verify`.
- **Manual:** [photocraft.cl](../../manuals/cl/photocraft.cl).
- **Contracts:** `run modules.verify-map()`, `run photocraft.verify-greeting()`.
- **Outcome contracts:** No outcome binding yet.
- **Dependencies:** None statically declared.
- **Owner:** Marketplace / Mods.
- **Files:** [apps/photocraft/host-contract.json](../../apps/photocraft/host-contract.json), [apps/photocraft/manual.cl](../../apps/photocraft/manual.cl), [apps/photocraft/neyvia.module.json](../../apps/photocraft/neyvia.module.json), [apps/photocraft/photocraft_mod.py](../../apps/photocraft/photocraft_mod.py).
