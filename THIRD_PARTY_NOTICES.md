## 7. Flags for Paul (not resolved here; nothing deleted)

1. **PyMuPDF was dropped (AGPL-3.0).** PDF text, page counts and generated PDFs use pypdf; page rendering uses
   pypdfium2 (PDFium). Both are permissive. Ship the PDFium third-party license file that the pypdfium2 wheel carries.
2. **Remotion needs a company license** for larger for-profit use. Confirm before any Remotion render ships
   in a commercial release. HyperFrames (Apache-2.0) and cinetic's HTML path avoid this.
3. **cool-retro-term is GPL-3.0.** Only ideas are used, as the plan says. Keep it that way: no copied shaders
   or CSS from it in the Terminal theme.
4. **Unknown origin skills.** Several skills in `~/.codex/skills` and `.codex/skills` (taste-skill family,
   imagegen, jbheaven-enhanced-workflow, refine-product-ui, tonal-ui-without-lines, etc.) have no license or
   author text. If they come from other people they need attribution, and their terms are unclear. Confirm
   the source of each before a public release.
5. **Card-console and LAYA license lines.** `tools/card-console` has no license file. `tools/laya` has an
   Apache-2.0 text but no copyright holder. Decide the license for both if they ship.
6. **cua-driver-win.** Binary runtime is downloaded, not committed. Add the upstream URL and copyright line
   before release.
7. **fframes.** The MIT claim is from the repo page only; the LICENSE file could not be opened in the scout
   (S6). Check the file before relying on it.
8. **Version mismatch.** Installed `openai-agents` is 0.18.3 while `pyproject.toml` pins `>=0.19.4,<0.20`.
   The environment used for this inventory is older than the pin. Re-run the inventory after `uv sync`.
9. **Rust crate licenses** were not read from the lockfile in this pass; run `cargo license` on a build machine.
