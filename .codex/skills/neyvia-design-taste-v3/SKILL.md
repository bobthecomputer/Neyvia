# Neyvia Design Taste V3 — Beauty Scout + Innovation Engine

The target is **familiar enough to understand, novel enough to remember, useful enough to keep**.

## Scout broadly

Do not search only SaaS dashboards or social-media concept shots. Inspect shipped developer tools, OS shells, launchers, terminals, creative software, music and video editors, industrial interfaces, scientific instruments, cameras, automotive HMI, games, editorial design, accessibility tools, and spatial systems.

A reference is strong when it survives repeated use, realistic density, multiple states, accessibility, and long-term refinement. Downgrade empty marketing dashboards, giant decorative type, glass without behavior, and concept-only mockups.

## Extract principles, never surfaces

For each reference record:

- observed move;
- underlying user/system problem;
- transferable principle;
- transfer boundary—where it would fail;
- a Neyvia translation expressed in Neyvia’s own grammar.

Build a principle library rather than a moodboard.

## Start from a real tension

Good invention resolves tensions such as:

- chat is linear while agent work is parallel;
- transparency is valuable while raw logs destroy readability;
- autonomy must coexist with reversible human control;
- preview needs space while conversational context must remain available;
- capability needs discovery while permanent controls create clutter;
- work has temporal history while ordinary UI shows only the present;
- agent identity helps while too many colors create noise.

## Invention operators

Deliberately explore:

- collapse two concepts into one;
- split one overloaded concept;
- move persistent UI into time/context;
- move hidden information into space;
- reassign modality—toolbar to command, modal to inline, list to spatial, page to sheet;
- invert the default;
- compress many events into one semantic object;
- expand an overcompressed failure into causal proof;
- make discrete modes continuous;
- make experimental action reversible;
- make routine state ambient;
- make compact state exactly inspectable.

## Morphological grid

Vary primary object, navigation, agent representation, time, detail disclosure, control ownership, verification representation, and density. Generate unusual combinations, then reject those without cognitive advantage.

## Novelty budget

Use familiar patterns for typing, navigation, selection, menus, forms, files, back/close, and destructive confirmation. Spend novelty where the product genuinely differs. Most production surfaces should remain roughly 80–90% familiar grammar and 10–20% distinctive invention.

## Concept tournament

For a major interaction produce at least:

1. conservative/best-practice;
2. reduction-first;
3. power-user;
4. spatial or temporal reframe;
5. wild but defensible.

Score clarity, beauty, learnability, novelty, task efficiency, scalability, accessibility, reversibility, implementation complexity, and product coherence. Do not automatically choose the most novel.

## Originality test

Before calling a concept innovative, state:

1. the existing pattern it departs from;
2. the real limitation it solves;
3. how the user discovers it;
4. what cognitive or interaction cost it reduces;
5. what new capability it creates;
6. how it scales and fails;
7. why it remains valuable without animation or marketing.

If the problem or reduced cost is unclear, it is novelty, not innovation.

## Cross-domain transfer

Use DAWs for lanes and automation, video editors for scrub-able non-destructive history, mission control for anomaly salience, cameras for expert controls with immediate feedback, games for progressive teaching, industrial controls for safety and redundancy, and editorial systems for content-led hierarchy.

Transfer the interaction principle, not the visual costume.

## Quality gate

Call a concept innovative and beautiful only when:

- rendered V2 score is at least 61/75;
- it improves comprehension, speed, discovery, recovery, density, transparency, control, continuity, or scale;
- the core interaction is naturally learnable;
- it fits the product grammar;
- it survives realistic states;
- it is recognizably Neyvia rather than a clone;
- it preferably removes complexity elsewhere.

The best target is: **I have not seen this exact interaction before, but it now feels obvious.**
